# Happy 2nd Anniversary, Karma ♥

A single-page anniversary surprise. Open `index.html` in a browser (or host it with GitHub Pages).

## Make it yours
Everything personal lives in the `CONFIG` block near the bottom of `index.html`:

- `startDate` – the day you got together (drives the live counter)
- `timeline` – your real memories (the current entries are prompts to replace)
- `reasons` – the flip cards
- `letter` – the love letter that types itself out
- `song` – optional: drop an mp3 next to `index.html` and put its filename here

## Host it on GitHub Pages
Repo **Settings → Pages → Deploy from branch**, pick the branch and `/ (root)`, and send her the link.
